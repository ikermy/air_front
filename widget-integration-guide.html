🎯 Руководство по интеграции MarusyaWidget

MarusyaWidget - это настраиваемый чат-виджет с поддержкой кастомизации позиционирования и стилей.

📦 Способы интеграции

🚀 Способ 1: Автоматическая инициализация (Рекомендуется)

Самый простой способ - виджет автоматически инициализируется при загрузке страницы.

Вариант 1.1: Через meta-тег

<!DOCTYPE html> <html> <head> <meta name="marusya-exam-key" content="ваш-exam-key"> </head> <body> <!-- Ваш контент сайта --> <!-- Подключение виджета --> <script src="https://ваш-домен.com/widget/marusya-widget.js"></script> </body> </html>

Вариант 1.2: Через data-атрибут скрипта

<!DOCTYPE html> <html> <body> <!-- Ваш контент сайта --> <!-- Подключение виджета с exam-key --> <script src="https://ваш-домен.com/widget/marusya-widget.js" data-exam-key="ваш-exam-key"> </script> </body> </html>

⚙️ Способ 2: Программная инициализация

Для полного контроля над виджетом используйте JavaScript API.

<!DOCTYPE html> <html> <body> <!-- Ваш контент сайта --> <!-- Подключение виджета без автоинициализации --> <script src="https://ваш-домен.com/widget/marusya-widget.js"></script> <script> // Ждем загрузки API window.addEventListener('load', function() { // Стандартная инициализация const widget = MarusyaWidget.init({ examKey: "ваш-exam-key" }); }); </script> </body> </html>

🎨 Способ 3: Инициализация с кастомизацией

Настройка позиции, размера и стилей кнопки виджета.

<script> // Кнопка в левом нижнем углу const widget1 = MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { left: '30px', bottom: '30px' }, buttonSize: { width: '60px', height: '60px' } }); // Кнопка в правом верхнем углу с кастомными стилями const widget2 = MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: '30px', top: '30px' }, buttonSize: { width: '55px', height: '55px' }, buttonStyle: { backgroundColor: '#ff6b6b', borderRadius: '15px', boxShadow: '0 8px 16px rgba(255,107,107,0.4)', border: '3px solid white' } }); // Большая кнопка с уникальным дизайном const widget3 = MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: '20px', bottom: '20px' }, buttonSize: { width: '80px', height: '80px' }, buttonStyle: { backgroundColor: '#4ecdc4', borderRadius: '50%', boxShadow: '0 10px 20px rgba(78,205,196,0.3)', border: '4px solid #45b7aa', transform: 'rotate(0deg)', transition: 'all 0.3s ease' } }); </script>

📋 Параметры конфигурации

Обязательные параметры:

  • examKey (string) - Уникальный ключ экзамена для авторизации

Опциональные параметры:

  • buttonPosition (object) - Позиция кнопки: { right, bottom, left, top }
  • buttonSize (object) - Размер кнопки: { width, height }
  • buttonStyle (object) - CSS стили для кнопки

🔧 Управление виджетом

// Инициализация виджета const widget = MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: '30px', bottom: '30px' } }); // Уничтожение виджета widget.destroy(); // Или через глобальный метод MarusyaWidget.destroy();

📱 Примеры для разных сценариев

🖥️ Десктоп сайт

MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: '30px', bottom: '30px' }, buttonSize: { width: '60px', height: '60px' }, buttonStyle: { backgroundColor: '#007bff', borderRadius: '50%', boxShadow: '0 4px 12px rgba(0,123,255,0.3)' } });

📱 Мобильная версия

// Адаптивное позиционирование const isMobile = window.innerWidth <= 768; MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: isMobile ? '15px' : '30px', bottom: isMobile ? '15px' : '30px' }, buttonSize: { width: isMobile ? '50px' : '60px', height: isMobile ? '50px' : '60px' } });

🎯 E-commerce сайт

MarusyaWidget.init({ examKey: "ваш-exam-key", buttonPosition: { right: '20px', bottom: '100px' }, // Выше корзины buttonSize: { width: '70px', height: '70px' }, buttonStyle: { backgroundColor: '#28a745', borderRadius: '50%', border: '3px solid white', boxShadow: '0 6px 18px rgba(40,167,69,0.4)' } });

⚠️ Важные моменты

  • Убедитесь, что у вас есть действующий examKey
  • Виджет автоматически скрывается на мобильных устройствах (ширина ≤ 425px)
  • Рекомендуется размещать скрипт перед закрывающим тегом </body>
  • Для HTTPS сайтов используйте HTTPS URL виджета

🚨 Отладка

// Проверка доступности API if (typeof MarusyaWidget !== 'undefined') { console.log('✅ MarusyaWidget API доступен'); console.log('Методы:', Object.keys(MarusyaWidget)); } else { console.error('❌ MarusyaWidget API не найден'); } // Проверка инициализации try { const widget = MarusyaWidget.init({ examKey: "test-key" }); console.log('✅ Виджет успешно инициализирован:', widget); } catch (error) { console.error('❌ Ошибка инициализации:', error); }

📞 Техническая поддержка

При возникновении проблем с интеграцией проверьте:

  • Корректность examKey
  • Доступность файла marusya-widget.js
  • Отсутствие конфликтов с другими скриптами
  • Консоль браузера на предмет ошибок
