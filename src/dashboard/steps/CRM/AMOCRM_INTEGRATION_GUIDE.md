# Руководство по интеграции с AmoCRM

## Обзор

Компонент `AmoCRMSection` предоставляет полноценную интеграцию с AmoCRM через OAuth 2.0 авторизацию.

## Основные возможности

### 1. Базовая настройка
- **Название конфигурации** - произвольное имя для вашей интеграции
- **Subdomain** - поддомен вашего аккаунта AmoCRM (из адреса `subdomain.amocrm.ru`)
- **Client ID** - идентификатор интеграции из личного кабинета AmoCRM
- **Client Secret** - секретный ключ из личного кабинета AmoCRM

### 2. Реальная OAuth авторизация

**Кнопка: "Авторизовать через OAuth"**

Выполняет полный цикл OAuth 2.0 авторизации:
1. Сохраняет конфигурацию на сервере
2. Получает URL для авторизации
3. Открывает popup окно AmoCRM
4. Пользователь авторизуется в AmoCRM
5. Обменивает код авторизации на токены
6. Сохраняет access/refresh токены

**Требования:**
- Разрешить всплывающие окна в браузере
- Код авторизации действителен 20 минут
- Нужен реальный аккаунт AmoCRM

### 3. Mock авторизация (для тестирования)

**Кнопка: "Mock авторизация (тестирование)"**

Создает тестовые токены БЕЗ реального подключения к AmoCRM:
- Не требует ngrok или внешнего доступа
- Не требует реального аккаунта AmoCRM
- Используется только для локальной разработки
- ⚠️ НЕ использовать в продакшене!

## Как получить Client ID и Client Secret

1. Войдите в свой аккаунт AmoCRM
2. Перейдите в **Настройки → Интеграции**
3. Нажмите **Создать интеграцию**
4. Заполните данные интеграции
5. Скопируйте **Client ID** и **Client Secret**
6. Укажите **Redirect URI**: `https://www.amocrm.ru/oauth`

## Индикаторы состояния

### Статус авторизации
- ✅ **Авторизовано** - токен активен
- ⚠️ **Токен истек** - требуется переавторизация

### Информация о токене
- Дата создания конфигурации
- Дата последнего обновления
- Срок действия токена

## Рабочий процесс

### Первая настройка
1. Заполните все обязательные поля (*)
2. Нажмите **"Сохранить конфигурацию"** (кнопка внизу)
3. Выберите тип авторизации:
   - **OAuth** - для реального подключения
   - **Mock** - для тестирования
4. Включите CRM переключателем "Статус"

### Переавторизация
1. Если токен истек, нажмите **"Переавторизовать через OAuth"**
2. Следуйте процессу авторизации заново

### Обновление настроек
1. Измените нужные поля
2. Нажмите **"Обновить конфигурацию"**
3. При необходимости выполните переавторизацию

## Устранение неполадок

### Ошибка: "Не удалось открыть окно авторизации"
- Разрешите всплывающие окна для вашего сайта

### Ошибка: "Истек срок ожидания авторизации"
- Код авторизации действует 20 минут
- Начните процесс заново

### Ошибка: "Токен истек"
- Нажмите кнопку переавторизации
- Access токены AmoCRM имеют ограниченный срок действия

### Ошибка: "Окно авторизации было закрыто"
- Не закрывайте окно авторизации до завершения
- Начните процесс заново

## Техническая информация

### Endpoint'ы API
- `POST /amocrm/api/crm/configs/amocrm` - сохранение конфигурации
- `POST /amocrm/api/api/v1/oauth/amocrm/auth` - получение auth URL
- `POST /amocrm/api/api/v1/oauth/amocrm/exchange` - обмен кода на токены
- `POST /amocrm/api/mock/oauth/auth` - mock авторизация (тестирование)

### Безопасность
- Используется OAuth 2.0 Authorization Code Flow
- State параметр для защиты от CSRF атак
- Client Secret передается только через защищенное соединение
- Токены хранятся на сервере, не в браузере

## Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что Client ID и Client Secret корректны
3. Проверьте, что subdomain указан правильно
4. Убедитесь, что Redirect URI настроен в AmoCRM
