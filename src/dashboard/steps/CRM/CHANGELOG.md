### 2. `CreateCRM.jsx` - Обновлена логика сохранения
**Изменения:**
- ✅ Кнопка "Создать Mock CRM" переименована в "Сохранить конфигурацию"
- ✅ Функция `handleSaveCRM` теперь только сохраняет базовую конфигурацию БЕЗ авторизации
- ✅ Авторизация (OAuth и Mock) вынесена в `AmoCRMSection` для лучшей организации
- ✅ Удален неиспользуемый импорт `createMockCRMAuth`
- ✅ Улучшены уведомления пользователю

**Новая логика:**
1. Пользователь заполняет поля в `AmoCRMSection`
2. Нажимает "Сохранить конфигурацию" в `CreateCRM`
3. Базовая конфигурация сохраняется на сервере (БЕЗ токенов)
4. Затем выбирает тип авторизации в `AmoCRMSection`:
   - "Авторизовать через OAuth" - реальная авторизация
   - "Mock авторизация" - тестовая авторизация
5. После успешной авторизации CRM готова к использованию

## API Endpoints используемые

### Конфигурация
- `POST /amocrm/api/crm/configs/amocrm` - создание/обновление конфигурации
- `GET /amocrm/api/crm/configs/amocrm` - получение конфигурации
- `DELETE /amocrm/api/crm/configs/amocrm` - удаление конфигурации
- `POST /amocrm/api/crm/configs/amocrm/active` - изменение статуса активности

### OAuth авторизация (реальная)
- `POST /amocrm/api/api/v1/oauth/amocrm/auth` - получение auth URL
- `POST /amocrm/api/api/v1/oauth/amocrm/exchange` - обмен кода на токены

### Mock авторизация (тестирование)
- `POST /amocrm/api/mock/oauth/auth` - создание mock токенов

### Health Check
- `GET /amocrm/health` - проверка доступности сервиса

## Безопасность

### OAuth 2.0 Flow
- Authorization Code Flow с PKCE
- State параметр для защиты от CSRF
- Токены хранятся на сервере, не в браузере
- Client Secret не передается в клиентский код

### Обработка ошибок
- Все ошибки API перехватываются и отображаются пользователю
- Детальное логирование для отладки
- Валидация данных перед отправкой

## Тестирование

### Mock режим
- Используется для локальной разработки БЕЗ реального AmoCRM
- Создает тестовые токены
- Не требует ngrok или внешнего доступа
- ⚠️ НЕ использовать в продакшене!

### Реальная авторизация
- Требует реальный аккаунт AmoCRM
- Требует создания интеграции в личном кабинете AmoCRM
- Требует правильных Client ID и Client Secret
- Popup окно должно быть разрешено в браузере
