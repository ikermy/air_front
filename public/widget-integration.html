🚀 Быстрый старт

Для подключения виджета Маруся AI на ваш сайт выполните следующие шаги:

1. Подключение с атрибутом data-exam-key

<script src="https://kermy.org/widget/marusya-widget.js" data-exam-key="${urlExamKey}"></script>

2. Альтернативный способ с мета-тегом

<meta name="marusya-exam-key" content="${urlExamKey}">
<script src="https://kermy.org/widget/marusya-widget.js"></script>

3. Программная инициализация

<script src="https://kermy.org/widget/marusya-widget.js"></script>
<script>
window.addEventListener('load', function() {
    if (window.MarusyaWidget) {
        window.MarusyaWidget.init({
            examKey: '${urlExamKey}'
        });
    }
});
</script>

📚 API Методы

MarusyaWidget.init(options)

Описание: Инициализирует виджет с заданными параметрами.

Возвращает: Объект с методами управления виджетом или null при ошибке.

MarusyaWidget.destroy()

Описание: Удаляет виджет с страницы.

Возвращает: undefined

Пример использования API:

// Инициализация виджета
const widget = window.MarusyaWidget.init({
    examKey: '${urlExamKey}',
    buttonPosition: { right: '30px', bottom: '30px' },
    buttonSize: { width: '60px', height: '60px' },
    colors: {
        buttonBackground: '#4caf50',
        windowBackground: '#ffffff'
    }
});

// Удаление виджета
window.MarusyaWidget.destroy();

Условная загрузка виджета

<script>
// Загружаем виджет только для определенных страниц
if (window.location.pathname.includes('/support') ||
    window.location.pathname.includes('/help')) {

    const script = document.createElement('script');
    script.src = 'https://kermy.org/widget/marusya-widget.js';
    script.setAttribute('data-exam-key', '${urlExamKey}');
    document.head.appendChild(script);
}
</script>

Динамическое управление виджетом

<button onclick="initWidget()">Показать чат</button>
<button onclick="destroyWidget()">Скрыть чат</button>

<script src="https://kermy.org/widget/marusya-widget.js"></script>
<script>
let widget = null;

function initWidget() {
    if (!widget && window.MarusyaWidget) {
        widget = window.MarusyaWidget.init({
            examKey: '${urlExamKey}',
            buttonPosition: { right: '30px', bottom: '30px' }
        });
    }
}

function destroyWidget() {
    if (window.MarusyaWidget) {
        window.MarusyaWidget.destroy();
        widget = null;
    }
}
</script>

🔧 Устранение неполадок

Виджет не загружается

  • Проверьте правильность URL скрипта
  • Убедитесь, что examKey указан корректно
  • Проверьте консоль браузера на ошибки
  • Убедитесь, что нет блокировщиков рекламы

Виджет не подключается к серверу

  • Проверьте интернет-соединение
  • Убедитесь, что сервер https://kermy.org:8083 доступен
  • Проверьте настройки CORS в браузере

Проблемы со стилями

  • Убедитесь, что нет конфликтов CSS
  • Проверьте z-index других элементов на странице
  • Используйте параметр colors для переопределения стилей
